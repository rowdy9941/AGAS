## Distinctions we must preserve

- **Role/template vs assistant vs runtime vs run.** The pinned Agency revision contains 295 source Markdown roles; an earlier catalog contained 279. Counts change upstream. Twelve exact roles ship here; the rest are indexed references until imported. Agency's statements about persona quality are source descriptions, not measured AGAS results.
- **Knowledge vs operational truth.** Working context, episodic history, source-backed facts, procedures, preferences, artifacts, domain records, predictions and secrets have different ownership, review and retention. A single vault makes approved information readable; it does not make every source globally visible or replace a mission database.
- **Conversation vs committed effect.** A CEO chat request starts an auditable intent. Task ownership, receipts, permissions, retries and verification still require an execution engine.
- **Continuous state vs continuous inference.** Executive/CEO identities and media account definitions persist. Inference workers activate only on admitted tasks with bounded concurrency.
- **Spatial simulation vs test/staging vs world model.** A software twin represents selected linked software objects; a preview runs actual code; predictive models require independent validation.
- **Self-improvement vs observed improvement.** Revised memory, prompts, routing, code and weights are different changes. Each requires provenance, baseline, regression and promotion criteria. No AGI or comparative speed/accuracy claim follows merely from combining tools.

## Checks before replacing the old branch

1. AGAS native hub/mission/context invariants persist after restart and backup/restore.
2. At least two actual runtime adapters complete a mission with artifacts, cancellation, duplicate-retry protection and evidence-backed acceptance.
3. Direct CEO conversations truly reach a selected runtime and summarize back to executive without leaking unrelated scoped context.
4. The one vault supports authorized import with revision conflicts and keeps credentials out of notes.
5. Dev and Content prove full representative user workflows; each other hub meets its own domain safety and data gates.
6. Windows/macOS/Linux clean installs and an accessible browser UI pass practical user tests. Compare performance to equivalent single-agent/AionUI/Paperclip workflows using the same tasks and hardware.

This map makes the present foundation reviewable without claiming the advanced phases already run.
